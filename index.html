      How to play

      1. Download the game: press “Download game.tar.gz” and save the file on your computer. The game can’t run without it.
      2. Mount it: press “Select game.tar.gz” and choose the file you just downloaded.
      3. Wait for the import to finish until the status above says “Ready to play”.
      4. Press “Start to play” and wait for the game to load.
      5. You only need to do this once: the game stays stored in this browser and works offline.
